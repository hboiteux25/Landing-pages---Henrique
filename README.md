# Landing Pages - Henrique

Projeto de landing pages de alta fidelidade desenvolvido com Vite, JavaScript e CSS moderno.

## Tecnologias
- Vite
- JavaScript (ES Modules)
- CSS (Glassmorphism & Terminal aesthetics)

## Como rodar
1. Instale as dependências: `npm install`
2. Inicie o servidor de desenvolvimento: `npm run dev`
